# Synthetic module handoffs

Seven scenarios, each with a real synthetic DOCX, 13 JSON checkpoints and a SHA256 manifest.
All files are generated by `python -m scripts.generate_parallel_fixtures` from the pinned
knowledge snapshot. Proposed findings and verification flags are fixture assumptions;
these files are not gold legal labels, approved knowledge or production provider output.

Start with [the five-person development guide](../../docs/parallel_development.md).
Check all checkpoints with `python -m scripts.parallel_dev --all-scenarios`.
Use `--person 1` through `--person 5` to isolate one development role, or
`--verify-output path/to/result.json` to check output from your own implementation.
